# إيثاركو — موقع خدمات ومساحات الأعمال

تطبيق React وTypeScript مبني باستخدام Vite، مع Supabase للحجوزات والخدمات والوسائط وإدارة الدخول.

## التشغيل

1. ثبّت الاعتماديات باستخدام `npm ci`.
2. انسخ `.env.example` إلى `.env.local` وأدخل رابط مشروع Supabase ومفتاحه العام. لا تستخدم مفتاح الخدمة السري في الواجهة.
3. شغّل `npm run dev`.

## التحقق

- `npm test`: اختبارات التحقق من الحجز والتخزين المحلي.
- `npm run typecheck`: فحص التطبيق وإعداد Vite.
- `npm run build`: فحص الأنواع وإنشاء نسخة الإنتاج في `dist`.
- `npm run preview`: معاينة نسخة الإنتاج محليًا.

## الصفحات والبيانات

الصفحات العامة: `/` و`/about` و`/privacy` و`/terms`.
الإدارة: `/admin` و`/admin/login` و`/admin/reset-password`.

التطبيق يتوقع جداول `admin_users` و`services` و`service_features` و`service_requests` و`site_media` و`site_social_links`، وحاوية التخزين `site-media`. مخطط قاعدة البيانات وسياسات الصلاحيات غير مضمنة في المستودع؛ يجب مطابقتها في مشروع Supabase قبل الاعتماد على النشر.

محرر النصوص ومعلومات التواصل يحفظان **معاينة محلية في المتصفح فقط**؛ تظهر التعديلات في الصفحات العامة في المتصفح نفسه، وتنتقل بين تبويباته. هذا ليس نشرًا عامًا للمحتوى. إدارة الخدمات والوسائط والطلبات وروابط التواصل تستخدم Supabase.

المكونات المستخدمة بالصفحات موجودة في `src/components/layout` و`sections` و`overlays` و`floating`. بقيت النسخ القديمة في جذر `src/components` للتوافق، ولا تستخدمها الصفحة الرئيسية. راجع `src/ARCHITECTURE.md`.

تفاصيل المراجعة وحدود الاختبارات موجودة في `REVIEW.md`.
